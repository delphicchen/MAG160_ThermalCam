# 引導式融合校正計畫（2026-10-12）

## 目標
讓其他使用者在自己的手機上，做出和 2026-10-12 雷射測距那次一樣好的校正
（新曲線在 0.3–4 m 目視全部對齊；見 `PLAN_TRIANGULATION.md` 第三、四輪）。
每支手機鏡頭與 Type-C 的相對位置不同 → 校正一定要每支手機自己做。

## 那次為什麼成功、舊校正為什麼失敗
| | 舊校正 | 2026-10-12 |
|---|---|---|
| 距離 | 存檔對話框預填 AF 估計，直接按存 | 雷射 / 捲尺實量 |
| 手機姿勢 | 近距離斜拿 | 正對目標 |
| 目標 | 不固定 | 有溫差、輪廓清楚（熱水杯、NUC） |
| 距離分布 | 多在 0.4–1.5 m | 0.3 m 到 4 m，近處較密 |
| ZOOM | 每點各調（2.13–2.64 亂跳） | 固定一個值（2.38） |
| 疊合用的曲線 | 逐點內插（照抄每個點的誤差） | 直線擬合（物理上就是 1/Z 的直線，誤差互相抵消） |

## 方案
### A. 改良現有流程（較小）
1. 存檔對話框：不再預填 AF 距離（改成灰字提示「鏡頭估計 x m，請以實量為準」）；
   快選改成 0.3 / 0.5 / 1 / 2 / ∞。
2. 已有 2 個以上距離後，ZOOM 固定為平均值，對齊時只調 X / Y（可解鎖）。
3. 3 個以上距離時，疊合改用直線擬合（`Fit.dxAt/dyAt`、zoom 平均），不再逐點內插；
   清單中殘差 > 3 px 的點標橘色，提示重做或刪除。
4. 對焦對照表：與其他點順序矛盾的對焦讀值（例：0.3 m 杯子讀到比 0.4 m 還小）不採用，該點仍用於曲線。
5. 「如何校正」說明卡（正對、溫熱且輪廓清楚的目標、實量距離、近遠都要）。

### B. 校正精靈（較完整，建議）
A 的 3、4 照做，另加一步一步的引導畫面：
1. 說明：準備一個熱的、輪廓清楚的東西（熱水杯）與量距工具（捲尺 / 雷射 / 地磚 60 cm）。
2. 遠處一點（≥ 3 m 或 ∞）：調 ZOOM + X + Y → 輸入實量距離 → 存。ZOOM 從此固定。
3. 近處三點（建議 1 m、0.5 m、0.3 m）：只調 X / Y → 輸入實量距離 → 存；
   每存一點立即顯示與直線的殘差，太大就請使用者重做。
4. 完成：顯示直線、各點殘差與對焦對照表點數；建議「物距 → 自動對焦」。

## 不做
- 影像比對自動校正（B5 構想）：比對在紋理多、多深度場景會錯，不能拿來當校正依據。

## 待使用者決定
A 或 B；直線擬合是否也套用到既有使用者的校正（≥ 3 個距離時）。
